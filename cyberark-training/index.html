WELCOME｜はじめに

CyberArk 新人研修サイト

特権アクセス管理（PAM）の考え方から、CyberArk製品の機能・設計思想・日常運用までを一通り学び、「先輩の横で実務を始められる」状態になることを目指します。

🔑

CyberArkを一言でいうと「会社中の“マスターキー”を、金庫に入れて、使うたびに記録し、使い終わったら鍵を作り替える仕組み」です。

この一文の意味が全部説明できるようになれば、研修は合格です。

研修全体像とゴール

研修は次の4フェーズで進めます。各フェーズの冒頭、各章の冒頭にも「全体像とゴール」を掲載しています。

フェーズ内容ゴール（できるようになること）目安時間
① はじめに出典・公式ナレッジ／用語集／本ページ学習の進め方と、困ったときに調べる場所（公式ドキュメント等）がわかる30分
② 学び全16章（基礎→製品→設計→運用→ハンズオン）各コンポーネントの役割・設計の考え方・運用の勘所を自分の言葉で説明できる15〜20時間＋ハンズオン6〜8時間
③ ケーススタディ基本編4題・応用編3題架空企業の要件から、設計判断・トラブル切り分け・インシデント初動を考えられる4〜6時間
④ 総まとめ練習問題ランダム出題の問題バンク正答率80%以上を安定して取れる（出題順・選択肢順は毎回変わります）1〜2時間×数回
⑤ 記録・提出成績・学習記録／講師用ページ学習記録を講師へ提出し、記述問題の講師採点・コメントを受け取る—
研修修了時の到達目標
  1. 「特権ID」とは何か、なぜ狙われるのか、PAMで何を防ぐのかを非エンジニアにも説明できる。
  2. CyberArkの主要コンポーネント（Vault / PVWA / CPM / PSM / PSM for SSH / PTA）と、SaaS版（Privilege Cloud）の構成要素を図で描ける。
  3. Safe・アカウント・プラットフォーム・Master Policyの関係を理解し、要件に合った設定案を作れる。
  4. パスワード変更失敗、セッション接続失敗などの典型トラブルを、ログと構成から切り分けられる。
  5. アプリケーションのシークレット管理、ZSP/JIT（ゼロ・スタンディング特権／ジャストインタイム）などモダンな領域の製品の位置づけを説明できる。

学びフェーズ：全16章

カードをクリックすると各章へ移動します。章末の「この章を完了にする」を押すと進捗に反映されます。

2つの提供形態をバランスよく（Self-Hosted 5：Privilege Cloud 5）

CyberArk PAMには、自社で構築する Self-Hosted と、SaaSの Privilege Cloud があります。本教材は両方を同じ比重で扱います。第5章で全体像を比べ、第3〜16章の章末にある「Self-Hosted と Privilege Cloud の違い（この章のポイント）」で、章ごとの差分を確認してください。

この教材の使い方

📘 マークの意味

身近な例え難しい概念を日常の例に置き換えます。
必ず覚える現場で必ず使う重点項目です。
事故につながるやってはいけないこと・誤解しやすい点です。
先輩の知恵運用現場で役立つ小技です。

🧭 フロー図の見方

処理の流れを説明する箇所では、図の下にラジオボタン（STEP 1, 2, 3 …）があります。STEPを選ぶと、図のその段階の矢印・部品だけが強調され、説明文が切り替わります。「次へ」ボタンでも進められます。

スマートフォンでは図を横にスクロールできます。
