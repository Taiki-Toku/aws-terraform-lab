# 画面キャプチャ差し込みガイド

各章の「画面キャプチャ差し込み枠」は、このフォルダに指定ファイル名の画像を置くと自動で画像に切り替わります（画像が無い間は取得手順が表示されます）。

| ファイル名 | 章 | 内容 |
|---|---|---|
| `ch03-pvwa-login.png` | 3 | PVWAのログイン画面 |
| `ch06-safe-members.png` | 6 | Safeメンバーと権限の設定画面 |
| `ch07-platform-settings.png` | 7 | プラットフォームの設定画面（変更・検証間隔） |
| `ch08-cpm-error.png` | 8 | CPMエラーが表示されたアカウント詳細 |

| `ch15-system-health.png` | 15 | コンポーネントの稼働状態画面 |

## 取得時のルール

- **検証環境の画面だけを使う**（本番・お客様環境の画面は使わない）
- 実在のホスト名・IPアドレス・ユーザー名・Safe名・社名は、架空の値（`hikari.example`、`lab-*` など）にするか、マスクする
- パスワード・トークン・証明書・QRコードが写っていないことを確認する
- 横幅1200〜1600px程度のPNGを推奨（スマートフォンでは自動縮小）
- 製品のバージョンが分かるよう、コミットメッセージ等に取得したバージョンを記録する
