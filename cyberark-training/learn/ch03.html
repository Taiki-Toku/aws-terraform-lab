すべての部品は「Vaultに接続しに行く」。Vaultは真ん中で金庫番をしているだけ。

3. 通信とポート

通信元 → 通信先ポート（既定）用途
PVWA / CPM / PSM / PSM for SSH / PTA → VaultTCP 1858Vault独自プロトコル（暗号化）での通信
利用者 → PVWATCP 443（HTTPS）Web画面・REST API
利用者 → PSMTCP 3389（RDP）PSM経由のセッション（HTML5 Gateway利用時はHTTPS）
利用者 → PSM for SSHTCP 22（SSH）SSHクライアントからの接続
CPM / PSM → ターゲットターゲットのプロトコル（例：SSH 22、RDP 3389、Windowsの管理系ポート、DBのリスナーポート等）パスワード変更・セッション中継
Vault → DR Vault（DRサービス）TCP 1858データ複製
「1858」は絶対に覚える

公式の「Network port definitions」でも、CPM・PVWA・PSM・PSM for SSH などからVaultへの通信は TCP 1858（既定。443などへの変更も可能） とされています。Vault関連の疎通トラブルの多くはFWでのTCP 1858遮断です。「PVWAでログインできない」「CPMがVaultに繋がらない」ときは、まずTest-NetConnection 10.10.10.11 -Port 1858（PowerShell）のように疎通を確認します。

4. 1回の特権利用で部品がどう連携するか

新人の高橋さんが、Linuxサーバ hk-web01 にPSM経由で接続する場面を例に、STEPを追ってみましょう。

トラブル時は「どの矢印が切れたか」で考える

上の図の矢印1本1本が、トラブルの切り分けポイントになります。例えば「PVWAにログインはできるがConnectで失敗」なら③〜⑤、「録画が再生できない」なら⑥を疑います。

Self-Hosted と Privilege Cloud の違い（この章のポイント）

🏢 Self-Hosted の場合

  • Vault・PVWA・CPM・PSM・PSM for SSH・PTAをすべて自社で構築・運用する
  • 各コンポーネントからVaultへ TCP 1858（既定）で接続
  • Web画面（PVWA）はIIS上に自社で構築

☁ Privilege Cloud の場合

  • Vaultと管理ポータル（PVWA相当）はSaaSとして提供される
  • 顧客側のコネクタは Connector Managementエージェント＋PSM が推奨構成。パスワード変更はSaaSの Secrets Rotation Service がエージェント経由で実行（CPMをコネクタに置く構成も選択可）
  • SSH中継はPSM for SSH（Unixコネクタ）、LDAP・SIEM連携はSecure Tunnel
  • コネクタからSaaSへの外向き通信は TCP 443 と 1858
  • 脅威検知はSaaSのThreat Detection and Response（ITDR）等で提供

出典（2026-10-19確認）：Privilege Cloud architecture、Deploy Privilege Cloud Connector、Network ports overview

振り返り問題（第3章）

Q1. Vaultの既定の通信ポートは？

  • TCP 443
  • TCP 1858
  • TCP 3389
  • UDP 514
TCP 1858です。PVWA・CPM・PSMなどはこのポートでVaultへ接続します。

Q2. ポリシーに従ってターゲットのパスワードを自動変更するコンポーネントは？

  • PVWA
  • PSM
  • CPM
  • PTA
CPM（Central Policy Manager）です。

Q3. PSM経由の接続で、利用者がパスワードを知らなくても接続できる理由は？

  • PSMが利用者の代わりにVaultからパスワードを取得し、代理でログインするから
  • ターゲット側でパスワード認証を無効化しているから
  • PVWAが利用者のPCにパスワードを自動入力するから
  • CPMが接続のたびにパスワードを空にするから
PSMが代理ログインするため、利用者はパスワードを見ません。これにより「パスワードを知っている人」を増やさずに済みます。

Q4. SSHセッションを中継・記録するLinux上のコンポーネントは？

  • PrivateArk Client
  • CPM
  • DR Vault
  • PSM for SSH（PSMP）
PSM for SSH（PSMP）です。WindowsのPSMとは別のコンポーネントです。
